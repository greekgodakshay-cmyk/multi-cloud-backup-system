Smilify Multi-Cloud Architecture & Specs

Enterprise Data Fabric & Disaster Recovery Topology

1. Zero-Trust Storage Architecture

Smilify decouples client requests from cloud storage providers using an authenticated backend facade:

  • Frontend Application: Pure responsive Web UI operating strictly against backend REST endpoints. No cloud tokens, secrets, or bucket names are exposed in browser code.
  • Backend Microservice: Node.js / Express engine utilizing the official AWS SDK for JavaScript v3 with unified S3-compatible protocol.
  • Primary Target: Cloudflare R2 provides high-performance, globally distributed storage with $0.00 egress costs.
  • Secondary Target: Backblaze B2 provides an independent geographic failure domain with 10 GB free forever and no credit card requirement.

3. Disaster Recovery (DR) Failover & Integrity

Every object is indexed with its cryptographic ETag hash. In the event of primary storage loss, the download route automatically fails over to the secondary replica, and the recovery route reconstructs the primary copy without data loss.
